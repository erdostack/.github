# erdostack

**Graph skills for coding agents.** Small, plain-markdown Agent Skills that teach a coding agent to work with graphs and graph databases.

This organization holds the name. The project itself is one repository on its author's account:

- Source: [usergraphtheory/erdostack](https://github.com/usergraphtheory/erdostack)
- Site: [erdostack.com](https://erdostack.com) ([中文](https://erdostack.com/zh/))
- Packages: [npm](https://www.npmjs.com/package/erdostack) and [PyPI](https://pypi.org/project/erdostack/)
- Announcements: [@graphtheory on X](https://x.com/graphtheory)

Status: pre-release. No skill has shipped yet.

Anything else using the name is not this project. The full list of official sources is on [the site](https://erdostack.com/#official).
